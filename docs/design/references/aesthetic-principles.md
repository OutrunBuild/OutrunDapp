# 可迁移审美原则（Stage-01 步骤 4 · borrow / adapt / do-not-copy）

> 每条原则回指 `source-id`。可读性红线冲突项显式标注「须关闭」。

## A. borrow-principle（可迁移原则）

1. **单一主光源 + 回声层**：黄是唯一主光源，品红只做错位复制回声，青只做功能点缀——强调层同源，数据层不参与发光。（BRAND，spec §2/§10；VS-002 黄字直读）
2. **光源在地平线，不在内容**：synthwave 渐变属于背景层的光，永远不压数据。（VS-001）
3. **暗底高密度列表可行**：深底 + 高对比浅色正文 + 霓虹仅做链接/强调色，列表型高密度内容不被风格破坏。（VS-004 editorial；VS-007 raw 列表）
4. **纹理分区而非全覆盖**：CRT 扫描线分色分区、有强弱起伏，不是整页贴图。（BRAND CRT 参数）
5. **终端隐喻界面化**：等宽/终端字用于数据与状态，靠字重/缩进/分隔线做层级，而非卡片嵌套。（VS-006/VS-007）
6. **磨损是细节不是画面**：碎片/撕裂/噪点用在字形边缘与分割线，保持内容区干净。（BRAND 碎片；VS-002 做旧）
7. **斜切与截角制造速度感**：方向性来自字形与分割线的角度，不靠渐变运动。（VS-002；BRAND 斜切）
8. **层级互斥**：一次只有一个视觉主体（VS-001 单屏主体制；VS-005 门户单焦点）——直接支撑和谐判据 3。
9. **双语层叠有专门设计**：中英同屏不挤排，字号/字重分层。（VS-003）

## B. adapt（需为交易数据改造）

1. **synthwave 日落渐变**（VS-001/USR-INBOX-004/005）：只能进背景层或纯营销段（首页 hero 一次性），**禁止**进入数据区/按钮/卡片；数据区一律实色。
2. **霓虹发光**（VS-002/VS-003/VS-005）：glow 只给强调层（活跃状态、主 CTA 的一次 hover 峰值）；价格/收益率/余额/表格关闭 glow，用高对比实色（红线 3）。关 glow 后仍须 AA。
3. **像素/终端字**（VS-005/VS-006/VS-007）：适合 data 角色（地址/hash/数字标签），不适合中文正文——中文正文需另配可读字族；tabular-nums 优先于风格字。
4. **做旧磨损**（VS-002/BRAND）：磨损密度必须低于品牌资产（资产是单标志，界面是持续阅读面）；仅用于分割线/装饰性数字/空态插画，禁止用于正文底纹。
5. **3D/CRT 场景化**（VS-005）：性能与 reduced-motion 代价高；降级为静态材质层 + 一个品牌 moment。
6. **品红/青高饱和**（VS-003）：作为功能色需先过对比度（品红 `#FF06B5` 在 `#0A0A10` 上正文对比不足，只可做强调/大字号）。

## C. do-not-copy（禁止复制）

1. 一切外部 logo、角色、专辑艺术、游戏键视、动画剧照、站点文案（VS-001~007 各 register 已列）。
2. 外站整页结构/布局克隆（VS-005 的 3D 房间、VS-006 的双栏工作台结构可借原理不可借形）。
3. brand/ 包画面照抄进界面（机制可引用，画面属于标志本体）。
4. AI 生成图填补参考缺口（runbook 明令禁止）。

## D. 须关闭才能过可读性红线的清单（步骤 6/9 逐项检查）

- 数据层任何 text-shadow/box-shadow glow（VS-002/003 证实的反例风险）。
- 正文/表格背景上的渐变叠加（VS-001 渐变仅限背景层）。
- 磨损纹理作用于正文底（VS-002 做旧仅限装饰边缘）。
- 多霓虹并排争夺焦点（BRAND spec：青禁与两霓虹大面积并排）。
