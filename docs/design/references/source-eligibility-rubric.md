# 来源资格 Rubric（版本 1 · 已冻结 2026-09-15）

> 冻结规则：本文件冻结后只增版本不原地改。评定先于计数；起始候选只用于发现，不预先视为合格。
> 唯一架构真相源：`docs/architecture.md`（§1、§10、§14、§18）。

## 1. 计数主类别（每个 source-id 只能选一个）

| 类别 | 定义 | 计入核验门 |
|---|---|---|
| `direct-style` | 实际网站页面，且至少观察到 5 项风格证据中的 3 项（见 §2），逐项记录截图依据 | 是（至少 4 个） |
| `web-design-case` | 能观察到实际网页结构或至少 2 个交互/状态，且有作者/制作方和原始项目 URL | 是（至少 2 个，与 direct 互不重复 source-id） |
| `adjacent-style` | 可用于原则学习，不能计入 direct（例：纯图片、无页面结构的品牌资产） | 否 |
| `gallery` / `reference-index` | 只作发现入口（Behance/Pinterest/StyleShift 索引页本身），不能自身计入 | 否 |
| `blocked` | 被反爬/地区限制/失效，从计数中排除，保留失败证据 | 否 |

## 2. `direct-style` 五项风格证据（≥3 项，每项回指截图）

1. 高对比暗底 / 霓虹光源
2. 复古显示字体或字形
3. 网格 / 扫描线 / 模拟纹理
4. 电影化构图或动效
5. 明确的 retro-futurist / cyberpunk 叙事语汇

## 3. 八维适用性与 N/A

步骤 4 对每个已核实来源做八维拆解（色彩/光源、字体字形、网格构图、材质纹理、图像插画、动效转场、交互反馈、信息密度）。
某维度对来源类别不适用时，按本 rubric 记录 `N/A` + 证据，不强行编造。

## 4. 特殊登记（非计数，但须评定）

- `docs/design/brand/`（字标/monogram/扫描线纹理）：按本 rubric 五维评定为 `direct-style` 用户来源（方向已确认的风格证据，非普通候选），步骤 4 优先八维拆解；但它不是被发现的网站页面，`countsTowardGate: false`，不占用 6 个网站来源名额。
- `docs/design/references/inbox/` 5 个纯图片文件（USR-INBOX-001~005）：无网站页面结构，评定为 `adjacent-style`，只用于原则学习，不计入核验门。
- 交易 UX 参考集站点（步骤 5）不得进入视觉审美清单，即使视觉上有霓虹元素。

## 5. 互斥计数

- 每个 source-id 只能选择一个计数主类别。
- direct 最低数量与 web-design-case 最低数量必须使用互不重复的 source-id。
- Behance/Pinterest 的单张图片、无作者和原始 URL 的 Pin、无来源拼图、AI 生成图不能单独计入。
- Behance/Pinterest 只作发现入口，只有可追溯作者和原始项目 URL 的具体案例才能进入已核实来源。
- StyleShift 只有在逐项打开其列出的原始网站或案例后才可计入（索引页本身为 `reference-index`）。

## 6. 检索停止条件

- 核验门：至少 6 个已核实网站设计来源（≥4 `direct-style` + ≥2 互不重复 `web-design-case`），每项有浏览器证据、截图 SHA256、日期、授权、分类。达到最低门立即停止。
- 上限：最多 3 轮检索或主动检索 150 分钟。未达到则停止自动检索，交人类决定补资源或降低范围。
- 网站被反爬/地区限制/失效时标 `blocked`，从计数中排除。

## 7. 每来源必填证据

`source-id`、标题、所有者、URL、来源类别、捕获日期、授权状态、截图 SHA256（桌面/移动）、观察目标、禁止复制的品牌元素、保留状态、截图方式（`captureMode`）。
