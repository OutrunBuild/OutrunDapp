# Direction Seed C — 霓虹编辑部（editorial-cyberpunk 主导 · synthwave 色彩化）

- **世界**：一份夜刊编辑部——杂志网格与新闻条律承载高密度交易信息，霓虹只做"油墨外的信号色"。
- **主导子风格**：cyberpunk editorial（VS-004 杂志网格暗底列表、VS-007 新swire 条律层级）。
- **从属子风格**：synthwave——完全色彩化（黄/品红/青的配色角色），无日落意象、无渐变。

- **色彩角色**：黄=品牌强调/选中态；品红=回声（标签/生命周期徽章）；青=链接/focus；正文=高对比浅色；表面=深灰阶分层（非纯黑）。
- **字体角色**：display=编辑感衬线或窄体大字（差异化来源：编辑部传统）；body=可读无衬线；data=等宽。
- **构图**：多列杂志网格+侧栏；分割线系统（粗细分级）替代卡片堆叠。
- **材质**：近无纹理；靠字重/留白/分隔线做质感（反 AI 套版：无渐变无 glow 的暗底系）。
- **动效**：一个品牌 moment——条目加载时的品红回声闪现（reduced-motion 关闭）；其余为状态反馈。
- **信息密度**：全站高密度基调（/portfolio、/pol 最受益）。
- **交易 UX 承载**：列表/表格/审阅流的密度天花板直接由编辑网格承载。
- **来源组合**：VS-004、VS-007、VS-003（双语层叠）、BRAND（色彩）。
- **风险**：编辑部结构+暗底容易滑向"新闻站"缺乏 Web3 产品的交互张力；品牌温度靠色彩层单薄支撑。
